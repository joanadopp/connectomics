Code associated with this publication:
https://www.biorxiv.org/content/10.1101/2025.02.12.637801v1

The code was written to calculate the synapse number per Mushroom Body compartment for different Gal4 drivers, based on HemiBrain data and by using the natverse.
It also includes the code to visualize the results in a plot comparing different drivers across compartments, as shown in Figure 2m.
